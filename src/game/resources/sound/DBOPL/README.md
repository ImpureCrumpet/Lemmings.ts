# DBOPL OPL2/OPL3 emulator

This directory contains Thomas Zeugner's 2019 TypeScript port of the DOSBox
DBOPL implementation. Source-file headers identify copyright held by the DOSBox
Team for 2002–2015 and license the implementation under GPL-2.0-or-later.

The complete GPL version 2 text is in `LICENSES/GPL-2.0.txt`, and the component
boundary and distribution implications are described in
`THIRD_PARTY_NOTICES.md` and `docu/DISTRIBUTION.md`.
